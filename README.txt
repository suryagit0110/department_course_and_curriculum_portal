MCA Department Course & Curriculum Portal
============================================

Files:
- index.html
- style.css
- department-logo.png

The portal is a static HTML + CSS website based on the supplied MCA_R25_Regulations.pdf.
It includes:
- Supplied Department of Computer Applications logo in the top-left header
- Programme overview and PEOs
- Complete semester-wise course structure
- All listed department electives
- Syllabus highlights for all structured Semester I-III courses
- Internship/Project section
- Course Outcomes for the structured core courses
- PSOs and POs
- Academic regulations/framework summary

Open index.html in a browser.
