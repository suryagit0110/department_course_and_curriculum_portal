About the Programme

The MCA is a 2-year postgraduate programme designed to provide practical knowledge of computer applications and software development, with emphasis on current and emerging areas of Computer Science and Technology.

🧩

Curriculum Features

  • Six-month industry internship
  • Socially relevant project using design thinking
  • Curriculum aligned with NEP 2020
  • Skill-based and problem-solving courses
  • Advanced areas including AI, ML, Deep Learning, Cloud and Big Data
🚀

Department Vision

To emerge as a renowned centre in computer applications for providing high-quality education and research to produce globally competent professionals with ethical values.

Programme Educational Objectives

PEO 1

Develop cutting-edge technical skills to succeed in career and as an entrepreneur.

PEO 2

Pursue higher education and research with critical thinking and problem-solving capabilities.

PEO 3

Demonstrate ethical, collaborative and leadership abilities in multidisciplinary domains.

03

Syllabus

Course-wise syllabus highlights from the supplied MCA R25/C25 curriculum document

Coverage: The portal now includes the syllabus area for all structured courses in Semesters I–III, the internship/project component, and a complete department-elective catalogue. Open a course to view its major topics.
25MC401 — Data Structures4 Credits

Module 1: Basic C programming, data types, operators, control statements, arrays, strings, pointers, structures, sorting and searching.

Module 2: Linked lists, stacks, queues, trees, binary search trees, graphs, adjacency representations, BFS and DFS.

25MC402 — Python Programming3 Credits

Module 1: Python installation, identifiers, keywords, variables, operators, data types, type conversion, indentation, control flow, strings, lists, tuples, sets, dictionaries, functions, modules and packages.

Module 2: Text/binary/CSV files, exceptions, object-oriented programming, classes and objects, NumPy, Pandas and Matplotlib, with practical Python programming.

25MC403 — Web Technologies2 Credits

Module 1: WWW, browsers, web servers, web architecture, HTML/HTML5, links, tables, forms, frames and CSS.

Module 2: JavaScript and DOM, PHP, form/file handling, sessions, WAMP/PhpMyAdmin, MySQL connectivity, Git/GitHub, GitHub Pages and Figma.

25MC404 — Computer Organization and Operating Systems4 Credits

Computer Organization: Register transfers, bus and memory transfers, arithmetic/logic/shift micro-operations, instruction codes, CPU, addressing modes, cache memory and I/O organization.

Operating Systems: OS concepts, processes, CPU scheduling, synchronization, deadlocks, memory management, paging, segmentation and virtual memory.

25MC405 — Probability and Statistics4 Credits

Descriptive statistics, central tendency, dispersion and skewness; probability, conditional probability and Bayes theorem; random variables; Binomial, Poisson and Normal distributions; correlation, regression and hypothesis testing including chi-square tests.

25MC406 — Software Engineering3 Credits

SDLC and process models, Agile/Scrum, requirements engineering, SRS, feasibility study, UML-based analysis/design, software testing, risk management, quality assurance, configuration management and testing tools.

25MC407 — Technical English Communication2 Credits

Module 1: Effective communication, communication barriers, digital communication, vocabulary, grammar, skimming/scanning, paragraph writing, summarizing, note making/taking and speaking practice.

Module 2: Disruptive technologies and ethical implications; clean energy; precision agriculture; entrepreneurship and start-up culture; report/letter/e-mail writing, data interpretation, listening and group discussion.

25MC408 — Database Systems4 Credits

Database architecture and data modelling, ER/EER diagrams, relational models and integrity constraints, SQL, views, triggers and PL/SQL, normalization and functional dependencies, transaction management, concurrency control, file organization and NoSQL systems.

25MC409 — Object Oriented Programming4 Credits

Module 1: JDK, JRE, JVM, bytecode, Java fundamentals, arrays, strings, classes, objects, constructors, overloading, access control, inheritance and packages.

Module 2: Abstract classes and interfaces, exception handling, multithreading, AWT/Applets/Swing, GUI event handling, Collection Framework and JDBC.

25MC410 — Computer Networks3 Credits

Module 1: Uses and types of computer networks, network technology, protocols, reference models, physical layer and guided/wireless transmission media.

Module 2: Data-link concepts, network-layer design and routing, congestion/QoS, IPv4/IPv6, ICMP/ARP, transport protocols TCP/UDP, DNS, electronic mail and WWW.

25MC411 — Organization Behavior3 Credits

Module 1: Nature and scope of Organizational Behavior, contributing disciplines, organizational context, perception, personality, attitudes, Johari Window and Transactional Analysis.

Module 2: Group dynamics, group development, cohesiveness, stress management, learning and reinforcement, organizational behavior modification, conflict dynamics and conflict-management approaches.

25MC412 — Soft Skills Laboratory1 Credit

Personality development and self-management, employability skills, career planning, SWOT analysis, Johari Window, goal setting, time management and stress management.

Communication skills, role-play, formal/semi-formal/informal communication, group discussions, résumé preparation, Statement of Purpose, presentation skills, mock interviews and workplace communication.

25MC413 — Socially Relevant Project using Design Thinking2 Credits

This curriculum component is a project course using design thinking to address a socially relevant problem. The course structure identifies it as a practical project component in Semester II.

25MC414 — Indian Knowledge Systems1 Credit · Binary Graded

Module 1: Definition, scope and significance of Indian Knowledge Systems; fields of study; Vedic, Buddhist, Jain and other traditions; major schools of thought; early contributions in mathematics, astronomy and medicine; Nalanda and Takshashila.

Module 2: Discipline-specific IKS, relevance to modern science and technology, preservation challenges, sustainable practices in agriculture/water/medicine and environmental ethics.

25MC501 — Cryptography & Network Security4 Credits

Cybersecurity, information security and network security; classical and modern cryptography; DES/AES; RSA, Diffie–Hellman, ElGamal and ECC; hashes, MACs and digital signatures; TLS/SSL, secure email, IPsec, intrusion detection and IoT/cloud security.

25MC502 — Full Stack Technologies4 Credits

Full-stack development from front-end design and user interfaces through server-side programming, database management and deployment.

The syllabus includes Java/JSP-JDBC integration, React, AngularJS, ASP.NET MVC/ADO.NET, Node.js, Express.js, MySQL and MongoDB/Mongoose CRUD operations.

25MC503 — Big Data Analytics4 Credits

Module 1: Big Data characteristics, sources, unstructured data, evolution, challenges, business intelligence, Data Science and analytics.

Distributed analytics: Hadoop, HDFS, YARN, MapReduce, combiners/partitioners, Hive, Pig, ETL, HQL, Pig Latin and Spark/RDD-based analytics with scalable data processing.

25MC504 / 25MC505 — Internship / Project12 Credits · Semester IV

The final semester is structured around the Internship/Project component. The curriculum foreword specifies a six-month industry internship as a programme feature.

Course & Programme Outcomes

Expanded course-outcome coverage for the structured MCA courses

Semester I — Course Outcomes

25MC401 · Data Structures

  1. Apply programming concepts to develop modular and efficient programs.
  2. Analyze strings, pointers and structures.
  3. Evaluate searching and sorting algorithms.
  4. Design linked lists, stacks and queues.
  5. Develop algorithms using trees and graphs.

25MC402 · Python Programming

  1. Apply Python syntax, data types and control structures.
  2. Use lists, tuples, sets and dictionaries for problem solving.
  3. Implement reusable code using functions, recursion and lambda expressions.
  4. Develop applications using object-oriented programming.
  5. Work with files, NumPy, Pandas and Matplotlib for data handling and visualization.

25MC403 · Web Technologies

  1. Apply HTML to structure web pages.
  2. Create static pages using forms, tables and links.
  3. Design pages using CSS.
  4. Implement JavaScript and form validation.
  5. Develop dynamic applications using PHP, MySQL, Git and Figma.

25MC404 · Computer Organization & OS

  1. Apply fundamental computer organization and architecture concepts.
  2. Analyze data flow, instruction execution and control operations.
  3. Evaluate memory hierarchy, cache and I/O organization.
  4. Analyze scheduling, synchronization and deadlocks.
  5. Design process, memory and resource-management strategies.

25MC405 · Probability & Statistics

  1. Apply measures of central tendency, dispersion and skewness.
  2. Apply probability, conditional probability and Bayes theorem.
  3. Analyze random variables and probability distributions.
  4. Evaluate relationships using correlation and regression.
  5. Apply hypothesis-testing techniques including chi-square tests.

25MC406 · Software Engineering

  1. Apply SDLC models and process frameworks.
  2. Apply requirements engineering, SRS and UML principles.
  3. Analyze structured and object-oriented software designs.
  4. Evaluate unit, integration, system, black-box and white-box testing.
  5. Create risk-management and quality-assurance strategies.

25MC407 · Technical English Communication

  1. Apply effective reading strategies for academic and technical texts.
  2. Structure information through note-making, summarization and paragraph writing.
  3. Evaluate professional communication through e-mails, reports and social messages.
  4. Develop presentations, group discussions and extempore speaking skills.
  5. Design and deliver research-based reports and presentations using communication tools.

Semester II — Course Outcomes

25MC408 · Database Systems

  1. Apply database concepts and architecture.
  2. Analyze conceptual data models using ER/EER diagrams.
  3. Evaluate relational models, integrity constraints, SQL, views, triggers and PL/SQL.
  4. Apply normalization and functional dependencies to reduce redundancy.
  5. Design transaction, concurrency-control and NoSQL mechanisms for scalable data processing.

25MC409 · Object Oriented Programming

  1. Apply Java programming fundamentals and OOP concepts.
  2. Analyze classes, objects, constructors, inheritance, interfaces and overloading/overriding.
  3. Evaluate packages, access control and exception handling.
  4. Design multithreaded Java applications.
  5. Develop GUI applications using AWT/Swing and database applications using JDBC.

25MC410 · Computer Networks

  1. Analyze OSI and TCP/IP models and network protocols.
  2. Examine physical-layer transmission media.
  3. Evaluate data-link protocols, framing and error control.
  4. Design network-layer solutions using routing and congestion control.
  5. Implement transport-layer protocols such as TCP and UDP.

25MC411 · Organization Behavior

  1. Apply Organizational Behavior principles to organizational contexts.
  2. Analyze perception, personality and attitudes in workplace behavior.
  3. Evaluate group dynamics, team behavior and stress-management strategies.
  4. Develop conflict-resolution strategies for workplace disputes.
  5. Design Organizational Behavior models addressing motivation, leadership, culture and engagement.

25MC412 · Soft Skills Laboratory

  1. Implement verbal, non-verbal and interpersonal communication skills.
  2. Analyze strengths, weaknesses, opportunities and challenges for career planning.
  3. Apply time and stress-management techniques.
  4. Develop a professional résumé and Statement of Purpose.
  5. Design and deliver presentations using visual aids and modern technology.

25MC413 · Socially Relevant Project

  1. Identify a socially relevant problem for project work.
  2. Apply design-thinking principles to understand the problem and users.
  3. Develop and document a practical project solution.
  4. Use feedback and iteration to improve the proposed solution.
  5. Present the project outcome and its social relevance.

25MC414 · Indian Knowledge Systems

  1. Apply basic concepts of Indian Knowledge Systems in contemporary contexts.
  2. Analyze selected indigenous practices in health, environment, water management and architecture.
  3. Evaluate ethical and ecological values related to sustainability and social responsibility.
  4. Develop informed understanding through reflection, discussion and illustrative examples.

Semester III — Course Outcomes

25MC501 · Cryptography & Network Security

  1. Examine cybersecurity, information security and classical cryptographic techniques.
  2. Implement and compare DES and AES block ciphers.
  3. Design public-key mechanisms using RSA, Diffie–Hellman, ElGamal and ECC.
  4. Assess hashes, MACs and digital signatures for integrity and non-repudiation.
  5. Develop layered security solutions using TLS/SSL, IPsec, intrusion detection and IoT/cloud security.

25MC502 · Full Stack Technologies

  1. Demonstrate Java Collection Framework and JSP–JDBC integration for server-side applications.
  2. Construct dynamic user interfaces using React and AngularJS.
  3. Investigate ASP.NET MVC and ADO.NET for data-driven applications.
  4. Construct scalable backend services using Node.js and Express.js.
  5. Integrate MongoDB persistence with full-stack applications using Mongoose CRUD operations.

25MC503 · Big Data Analytics

  1. Examine Big Data characteristics and analytics techniques.
  2. Apply Hadoop, HDFS and YARN for distributed data management.
  3. Develop MapReduce programs using combiners and partitioners.
  4. Evaluate Hive and Pig for ETL, querying and analytics.
  5. Design Spark-based analytics workflows for scalable data processing.
